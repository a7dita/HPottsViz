Model equations, numerical method & reproducibility

All four models use the same symmetric, diluted Hebbian network, sparse random memories and partial cue. The activity energy is F₀ = −½σ·Jσ + U∑σactive + (1/β)∑σ log σ, including the inactive category.

Seeds are reproducible within HPottsViz. The browser uses Mulberry32, so the same numeric seed does not generate the same network or noise sequence as Fortran HPotts. The full-run download includes parameters, memories, graph, initial state, trajectory and the latest state. Parameters are held fixed while a run is active.
